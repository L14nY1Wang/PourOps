统计口径说明

  • 统计日期按酒吧营业日划分（北京时间当日 07:00 至次日 07:00，例如 01-11 统计 01-11 07:00 至 01-12 07:00）。
  • 销售走势图表与按日趋势明细已归入工作空间数据分析页面。
  • POS 实收按支付流水统计，同一张订单在区间内拆分付款只算一张，未付款不计。
  • 毛利＝营业额 − 商品成本，不是净利润（未扣人工、房租、水电、损耗）。
  • 库存状态与告警为当前快照（在售酒桶已售超 50% 或零售库存 ≤ 3 件），不随上方时间筛选变化。
  • 明细见销售订单记录与营运流水。
